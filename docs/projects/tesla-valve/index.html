The point of the valve

Code generated with careful intent flows forwards easily, and is improved at every step by deliberate resistance. Fast checks, evaluation, review and attestation return actionable feedback before promotion. The output is robust, resilient and reliable software running in production.

Humans define what the software should do and how to judge it. Agents and automation carry out the work. Production feedback improves the next specification, the checks and the delivery system.
